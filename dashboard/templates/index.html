El sistema

Evaluación de solicitudes de crédito

Contexto

Un banco evalúa solicitudes de crédito de forma automática. Cada semana del curso construyó y probó uno de los componentes de este sistema, y el pipeline DevOps garantiza que ningún cambio defectuoso llegue a producción. Un error de un centavo o de un punto de score en el borde de una regla aprueba a quien no debía o rechaza a un cliente válido.

Regla de aprobación vigente (política {{ P.version }})

  • Edad del solicitante18 a 65 años
  • Score crediticio válido{{ P.score_dominio[0] }} a {{ P.score_dominio[1] }}
  • Score mínimo de aprobación{{ P.score_minimo_aprobacion }}
  • Ingreso mensual mínimo{{ "{:,.2f}".format(P.ingreso_minimo) }}
  • Cuenta del clienteActiva
